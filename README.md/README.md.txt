# E-Commerce Dynamic Pricing and Elasticity Analytics

## Project Overview

This project analyzes e-commerce product pricing data to understand pricing trends, discounts, product performance, stock status, ratings, and customer reviews.

The project uses Python, SQL, Excel, and Power BI to perform data cleaning, analysis, visualization, and generate business insights.

## Objectives

- Analyze product pricing and discount patterns
- Identify pricing trends over time
- Analyze product categories and stock status
- Study ratings and review patterns
- Identify useful business insights for pricing decisions
- Create an interactive Power BI dashboard

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL / MySQL
- Microsoft Excel
- Power BI

## Dataset

The dataset contains e-commerce product pricing information from 2020–2026.

Key columns include:

- Date
- Platform
- Product Category
- Model Name
- Condition
- Launch Price
- Current Price
- Discount Percentage
- Sale Event
- Stock Status
- Rating
- Reviews Count
