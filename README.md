# E-commerce Dynamic Pricing and Elasticity Analytics

## Project Overview
This project analyzes Apple product pricing data to understand pricing trends, demand elasticity, and business insights using Python, pandas, and MySQL.
The project demonstrates a complete data   analytics workflow, including data cleaning, validation, exploratory data analysis (EDA), SQL analysis, and business insights.
-----
## Objectives
- Clean raw pricing data.
- Validate data quality
- Perform Exploratory Data analysis (EDA)
- Analyze pricing trends
- Generate SQL- based KPIs
- Understand pricing elasticity
- Provide business recommendations
-----
## Dataset
The dataset contains Apple product information, including:
- Product Name
- category
- Price
- Discount percentage
- Ratings
- Reviews

- Most products are in stock.
